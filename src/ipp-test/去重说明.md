# ipp_resource_field_mapper 表去重步骤

按「原始字符串 + 标准字符串 + 字段」视为同一条，只保留每组中 **id 最小** 的那一行，其余删除。

---

## 一、在 MySQL 里执行（推荐先查再删）

### 1. 先看有多少重复（可选）

```sql
-- 查看哪些 (original_str, standard_str, field) 出现多于 1 次
SELECT original_str, standard_str, field, COUNT(*) AS cnt
FROM ipp_resource_field_mapper
WHERE is_delete = 0
GROUP BY original_str, standard_str, field
HAVING COUNT(*) > 1;
```

### 2. 去重：每组只保留 id 最小的那条

**方式 A：直接删除「重复行」（保留每组最小 id）**

```sql
DELETE t1
FROM ipp_resource_field_mapper t1
JOIN ipp_resource_field_mapper t2
  ON t1.original_str = t2.original_str
 AND t1.standard_str = t2.standard_str
 AND t1.field = t2.field
 AND t1.id > t2.id;
```

- 效果：同一组 `(original_str, standard_str, field)` 只保留 **id 最小** 的那一行，其余删除。
- 若希望保留 **id 最大** 的，把 `t1.id > t2.id` 改成 `t1.id < t2.id`。

**方式 B：先查出要保留的 id，再删除不在其中的（适合先核对再删）**

```sql
-- 1）先看将要保留的 id 有多少行（应接近 93）
SELECT COUNT(*) FROM (
  SELECT MIN(id) AS id
  FROM ipp_resource_field_mapper
  WHERE is_delete = 0
  GROUP BY original_str, standard_str, field
) t;

-- 2）确认无误后再执行删除：删除「不在“每组最小 id”里」的行
DELETE FROM ipp_resource_field_mapper
WHERE id NOT IN (
  SELECT id FROM (
    SELECT MIN(id) AS id
    FROM ipp_resource_field_mapper
    WHERE is_delete = 0
    GROUP BY original_str, standard_str, field
  ) t
);
```

---

## 二、若已软删除也要一起去重

如果重复数据里有的行 `is_delete = 1`，也想按同一规则去重（每组只留一条），可以去掉 `WHERE is_delete = 0`，例如方式 A 改为：

```sql
DELETE t1
FROM ipp_resource_field_mapper t1
JOIN ipp_resource_field_mapper t2
  ON t1.original_str = t2.original_str
 AND t1.standard_str = t2.standard_str
 AND t1.field = t2.field
 AND t1.id > t2.id;
```

（不限制 is_delete，对所有行按组去重。）

---

## 三、执行后检查

```sql
SELECT COUNT(*) FROM ipp_resource_field_mapper WHERE is_delete = 0;
```

应接近 93。若仍偏多，再跑一遍「先看有多少重复」的查询，看是否还有重复组。

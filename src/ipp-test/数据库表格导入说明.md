# 将数据库中的 ipp_resource_field_mapper 表导入本项目

您提供的表格结构为：`id`, `original_str`, `standard_str`, `multiple`, `field`, `is_delete`, `user_name`, `create_at`，与本项目的 `ipp_resource_field_mapper` 表一致。可按以下任一方式导入。

---

## 方式一：用 data.sql 启动时自动导入（推荐）

1. **从原库导出为 INSERT 语句**
   - 在您当前使用的数据库客户端中，对 `ipp_resource_field_mapper` 表执行“导出为 SQL”或“生成 INSERT 语句”，得到类似：
   ```sql
   INSERT INTO ipp_resource_field_mapper (id, original_str, standard_str, multiple, field, is_delete, user_name, create_at)
   VALUES (40281, '毫米', 'mm', 1, 1, 0, NULL, '2025-08-19 09:15:53'),
          (40282, '米', 'm', 1, 1, 0, NULL, '2025-08-19 09:15:53'),
          ...
   ```

2. **替换本项目的 data.sql**
   - 打开：`src/ipp-test/src/main/resources/data.sql`
   - 保留或删除原有的两条测试数据，将上面导出的 **全部 INSERT 语句** 粘贴进去并保存。
   - 若原表主键是自增且希望 H2 自增，可只导出除 `id` 外的列，例如：
   ```sql
   INSERT INTO ipp_resource_field_mapper (original_str, standard_str, multiple, field, is_delete, user_name, create_at)
   VALUES ('毫米', 'mm', 1, 1, 0, NULL, '2025-08-19 09:15:53'),
          ('米', 'm', 1, 1, 0, NULL, '2025-08-19 09:15:53');
   ```

3. **启动应用**
   - 运行 `IppTestApplication` 或执行：`mvn spring-boot:run`
   - 应用启动时会自动执行 `schema.sql` 建表，再执行 `data.sql` 插入数据，表格即导入到 H2 内存库。

---

## 方式二：在 H2 控制台里执行 SQL

1. 启动本项目，访问：`http://localhost:8080/h2-console`
2. 连接配置：
   - **JDBC URL**: `jdbc:h2:mem:testdb`
   - **User Name**: `sa`
   - **Password**: `password`
3. 在 SQL 输入框中粘贴从原库导出的 **建表语句**（若表已存在可跳过）和 **INSERT 语句**，点击执行即可。

---

## 方式三：用 API 批量导入

若原数据在 Excel/CSV 或其它库中，可写脚本调用本项目的 REST 接口逐条插入：

- **POST** `http://localhost:8080/api/ipp/resource-field-mapper`
- **Content-Type**: `application/json`
- **Body 示例**（可不传 `id`，由库自增）：
```json
{
  "originalStr": "公分",
  "standardStr": "cm",
  "multiple": 1,
  "field": 1,
  "userName": null
}
```

批量时循环请求上述接口即可。

---

## 字段与图片表格对应关系

| 图片/数据库列名 | 本项目实体字段 | 说明 |
|----------------|----------------|------|
| id             | id             | 主键，可选自增 |
| original_str   | originalStr    | 原始字符串（如：毫米、公分） |
| standard_str   | standardStr    | 标准字符串（如：mm、cm） |
| multiple       | multiple       | 倍数，图中多为 1 |
| field          | field          | 字段，图中多为 1 |
| is_delete      | isDelete       | 0=未删除，1=已删除 |
| user_name      | userName       | 可为 null |
| create_at      | createAt       | 创建时间 |

按上述任一种方式导入后，即可通过接口查询（如 GET `/api/ipp/resource-field-mapper/all`）或 H2 控制台验证数据。

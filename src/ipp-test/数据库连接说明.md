# 数据库连接说明：连接的是库还是单张表？

## 结论先说

- **连接层面**：只能连接**整个数据库**（一个库 / 一个 schema），不能“只连接某一张表”。这是 JDBC 的机制：连接的是数据库实例里的一个库，不是单表。
- **使用层面**：连接库之后，你的项目**可以只使用其中一张表**。本项目目前只操作 `ipp_resource_field_mapper` 这一张表，所以你在库里只会看到这张表的数据在变化，**效果上就像“只连了这张表”**，在数据库客户端里打开这张表就能直观看到增删改查的结果。

---

## 具体关系

| 概念 | 说明 |
|------|------|
| **连接对象** | 一个数据库（例如 MySQL 的某个 database，或 H2 的某个 schema） |
| **连接方式** | 在配置里写：`url`（指向某个库）、`username`、`password` |
| **项目用到的表** | 由代码决定。本项目只有 Mapper 操作 `ipp_resource_field_mapper`，所以只会读写这一张表 |
| **在客户端里看** | 用 Navicat / DBeaver / 命令行等连接**同一个库**，打开表 `ipp_resource_field_mapper`，即可看到 Postman/应用里做的增删改查 |

所以：**连接的是整个库，但项目只动一张表；你要直观看到操作结果，就连接同一库并看这张表即可。**

---

## 让操作直观显示在数据库表格里：两种方式

### 方式一：继续用 H2，用自带的 Web 控制台看表

当前项目用的是 **H2 内存库**，数据在应用进程里，重启就清空。

- 启动应用后访问：`http://localhost:8080/h2-console`
- JDBC URL：`jdbc:h2:mem:testdb`，用户名 `sa`，密码 `password`
- 在控制台执行：`SELECT * FROM ipp_resource_field_mapper;`
- 在 Postman 里做增删改查后，刷新这条查询，就能**直观看到表格数据变化**。

适合本地快速验证，无需安装其他数据库。

---

### 方式二：改用 MySQL（或其它持久化库），用任意客户端看同一张表

若你希望：

- 数据**持久化**（重启应用不丢），且  
- 用 **Navicat、DBeaver、DataGrip** 等连接数据库，直接打开 `ipp_resource_field_mapper` 表查看，

就需要把项目从 H2 改为连接 **MySQL**（或你已有的其他数据库）。

步骤概要：

1. **在 MySQL 里建一个库**（例如 `ipp_test`），不需要先建表（应用可用 schema.sql 建表，见下）。
2. **在项目里配置连接这个库**：改 `application.properties` 的 `url`、`username`、`password`，并加上 MySQL 驱动（若尚未添加）。
3. **启动应用**：应用会连到该库，并按 `schema.sql` 建表、按 `data.sql` 初始化数据（若开启初始化）。
4. **用客户端连接同一个库**：在 Navicat/DBeaver 里连接同一库，打开表 `ipp_resource_field_mapper`，之后在 Postman 里的增删改查都会**直接反映在这张表里**。

这样仍然是“连接整个数据库”，但项目只使用并显示在这一张表上。

下面给出 **MySQL 配置示例**（复制到 `application.properties` 或使用 `application-mysql.properties` 并激活 `mysql` profile 即可）。

---

## MySQL 配置示例（连接整个库，项目只用一张表）

### 1. 添加 MySQL 驱动（若使用 MySQL）

在 `pom.xml` 的 `<dependencies>` 里增加（与 H2 并存即可，通过配置切换）：

```xml
<dependency>
    <groupId>com.mysql</groupId>
    <artifactId>mysql-connector-j</artifactId>
    <scope>runtime</scope>
</dependency>
```

### 2. 配置文件：连接“整个库”

创建或修改为连接某个**库**（不是某张表），例如：

```properties
# 连接的是「整个数据库」ipp_test，不是某一张表
spring.datasource.url=jdbc:mysql://localhost:3306/ipp_test?useUnicode=true&characterEncoding=utf-8&serverTimezone=Asia/Shanghai
spring.datasource.driver-class-name=com.mysql.cj.jdbc.Driver
spring.datasource.username=root
spring.datasource.password=你的密码

# 建表与初始数据（首次启动时执行，表会在该库里创建）
spring.sql.init.mode=always
spring.sql.init.schema-locations=classpath:schema.sql
spring.sql.init.data-locations=classpath:data.sql
```

- 这里 `ipp_test` 是**库名**，连接后项目可以访问该库下所有表；  
- 当前代码**只访问** `ipp_resource_field_mapper` 这一张表，所以你在库里只关心这张表即可，操作会直观显示在这张表里。

### 3. 在数据库客户端里查看

- 用任意客户端连接 **同一库** `ipp_test`（同一地址、用户、密码）。
- 打开表 **`ipp_resource_field_mapper`**，即可看到 Postman/应用中的增删改查结果。

---

## 小结

| 问题 | 答案 |
|------|------|
| 能只连接“某一个表格”吗？ | 不能。连接的是**整个数据库（一个库）**。 |
| 能只“用”某一个表格吗？ | 能。本项目只操作 `ipp_resource_field_mapper`，效果就是只用到这一张表。 |
| 怎么直观看到操作在表格里？ | 用 H2 控制台查这张表，或改用 MySQL 后用客户端连接同一库、打开这张表即可。 |
